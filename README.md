# Smart Agriculture Database System

A relational database that brings all of a farm's data into one organized place: farms, farmers, fields, crops, sensors, smart irrigation, weather, and suppliers.

## Why It Matters🌟
Farm data is often scattered across notebooks and spreadsheets, which makes it hard to make good decisions. This system connects everything together so farmers can:

- Track crops from planting to harvest.
- Link sensor readings to irrigation and save water.
- Compare harvest results with weather conditions.
- Make data-driven decisions that boost productivity and reduce waste.

## What's Included
- ER diagram
- Relational schema
- Sample data tables
- SQL file to build the database
